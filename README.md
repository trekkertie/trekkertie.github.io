# MeritCard - A simple merit card reward application
MeritCard is a simple app based on a school reward scheme. The app provides colour coded cards that contain twenty-five boxes. Each box can be 'stamped' by selecting it and tapping the icon to change it to a tick. An optional comment can also be added. Once the card is complete, by ticking all the boxes, the next card in the sequence is unlocked. Boxes can also be unticked to remove a merit.

It is up to you how you award merits. They could be awarded for good work, good behavious, politeness or anything you reagrd as merit worthy.
